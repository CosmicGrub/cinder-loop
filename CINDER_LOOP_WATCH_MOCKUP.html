Static mockup — no live data channel

Every value on the face above — hearts, timer, biome name, room count — is a fixed sample, chosen to show what a run-status view could look like. Nothing here is reading a real run: the game (cinder-loop.html) is a single offline file with no server and no network by design (L2), so there is currently no channel that could tell a separate watch anything in real time. The run timer above genuinely ticks — it is real elapsed time since this preview loaded, not simulated gameplay.

A real live version needs one of two things neither of which exist yet: a local network bridge (the desktop build optionally running a tiny status server, a watch browser connecting to it over the same LAN — new networking code, and a deliberate exception to L2 for this one optional feature only), or a native Wear OS companion app in Kotlin using Android's Data Layer API, which is a wholesale separate project in a different language and toolchain, not an extension of this one.

Sized to the Galaxy Watch6 Classic's native resolution — 480×480, round 1.5" AMOLED. Verified rendering with zero console errors at exactly that pixel size in real headless Chromium. Not verified on physical Wear OS hardware — no device was available to this session, and Wear OS has no standard path to sideload an arbitrary HTML file the way a phone browser can install a PWA, so that claim is not made here.

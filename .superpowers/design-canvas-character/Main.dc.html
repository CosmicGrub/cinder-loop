Cinder Loop · Character Rendering

Three directions for the same figure

The identity itself isn't up for debate — hooded, ash-cloth over a banked ember, one glowing ember-red eye under the hood. What's open is HOW that identity gets rendered: same tiny procedural stick-figure as today, or something with real visual weight.

Locked: hooded ash-cloth · banked ember · this session's own canon
Option A
Enhanced Procedural

Same technique as today — 100% vector, canvas-drawn, zero image assets — but far more visual care: gradient-shaded cloth, a rim-lit hood, a real glow around the ember, fold detail instead of flat trapezoids. Roughly 8× the on-screen scale of the current 22px figure.

Tradeoff

Lowest risk of the three. No new asset pipeline, no file-size growth, and it fully preserves the game's own real rule that hitboxes are baked directly FROM this rig (D6/L9) — nothing about that guarantee has to change.

Option B
Painterly Overlay

The same silhouette and pose as A, still fully procedural/vector — but rendered with a softer, more atmospheric hand: layered glow instead of a hard-edged ember, a subtle grain texture over the cloth, hazier gradients. Reads more like painted concept art than clean vector.

Tradeoff

Same low architectural risk as A (still hitbox-safe, still zero assets) — the cost here is runtime: SVG filters (blur, turbulence) are cheap for a mockup, but a canvas equivalent every frame at 60fps needs real profiling before committing.

Option C
Illustrated Sprite Art

Real hand-painted/illustrated sprite frames instead of procedural drawing — the highest visual ceiling of the three, genuinely closer to a finished game character. This sketch is a rough style/mood reference only; Claude Design can't produce real production game art.

Real cost, not undersold

A full animation pipeline: many painted frames × every move × all 4 weapons, embedded as base64 image data in the single offline HTML file (real file-size growth). And it breaks the game's own existing guarantee that hitboxes are baked FROM this rig (D6/L9) — hand-drawn art would need new infrastructure just to stay in sync with hitboxes, not simply "more expensive."

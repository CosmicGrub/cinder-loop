How should rooms connect to each other?

This decides whether a level is one gauntlet-like path, or something you can actually get lost in.

A — Linear chain (Dead Cells' own biomes)

One path forward. Every room is mandatory, in a fixed order. Simple to generate, simple to fairness-audit (50-gen.js's own D3a already does this per-level and would extend cleanly, room by room). Matches what you'd get playing a Dead Cells biome start to exit.

B — Branching graph, with optional rooms

A branch point offers a choice of route (harder room w/ better reward vs. safer room), like Dead Cells' own optional side-rooms/scrolls. More generation complexity — the fairness audit has to reason about a graph, not a line — and more meaningful player choice.

A

Linear chain

Simpler to build and to keep fair. Recommended as the v1 scope — branching can be a later, additive pass.

B

Branching graph

More interesting, real scope increase — the generator and fairness audit both get meaningfully harder.
